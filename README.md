# Banking Analytics – SQL Project

## Project Overview

This project focuses on analysing banking data using SQL to generate business insights across customers, branches, accounts, transactions, and loans.

## Objectives

- Analyse customer and account information
- Evaluate transaction activity and banking performance
- Analyse loan portfolios and loan payments
- Compare branch-level performance
- Identify key business trends and customer insights

## Database Structure

The project includes the following tables:

- Customers
- Branches
- Accounts
- Transactions
- Loans
- LoanPayments

## SQL Techniques Used

- SELECT, WHERE, GROUP BY, HAVING
- JOINs
- Aggregate Functions
- CASE Statements
- Subqueries
- Common Table Expressions (CTEs)
- Window Functions
- Ranking and Business KPIs

## Key Analysis

- Customer and account analysis
- Transaction analysis
- Loan portfolio analysis
- Loan payment analysis
- Branch performance analysis
- Customer and business KPI analysis

## Tools & Technologies

- MySQL
- SQL
- MySQL Workbench
